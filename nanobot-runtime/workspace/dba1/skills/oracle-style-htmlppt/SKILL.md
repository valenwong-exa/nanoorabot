# Oracle Style HTML PPT

本 Skill 用于基于 `oracle_slide_template` 模板目录，生成 Oracle 风格的 HTML 幻灯片，并输出可直接浏览的主页面。

## 与其它 Skill / Tools 协同

- 使用 `read_file` 读取用户提供的文稿文件与模板文件
- 使用 `list_dir` 校验模板目录与必要文件是否齐全
- 使用 `write_file` 在新建输出目录中生成页面，不在模板原目录覆写
- 生成后可用本地打开方式访问主页面进行预览

## 何时使用

- 用户明确要求“制作 Oracle 风格 slide/ppt”
- 用户提供了待排版文稿文件，且希望输出为 HTML 幻灯片
- 用户要求使用工作区既有 Oracle 模板进行统一风格设计

## 输入与识别规则

- 模板根目录固定为SKILL oracle-style-htmlppt的目录：`oracle_slide_template/`
- 文稿输入文件由用户提供，通常位于该目录或其子目录
- 先识别并校验以下模板资源是否存在：
  - `slide_main.html`
  - `slide_title.html`
  - `slide_agenda.html`
  - `slide_page_1.html`
  - `slide_page_left_right.html`
  - `slide_page_3_cols.html`
  - `slide_page_4_cols.html`
  - `slide_page_swot.html`
  - `slide_section_title.html`
  - `slide_end.html`  
  - `agenda.png`
  - `end.png`
  - `page.png`
  - `section_title.png`
  - `slide1.png`

## 标准执行策略

- 先做“页结构设计”，再做“逐页落地”，最后做“主页面组装”
- 页面类型必须限制在模板已提供类型范围内
- 模板复用率必须 ≥ 90%：整套内容页中，90%以上页面必须直接使用既有模板，不得自行创作新格式
- 除非用户明确要求新布局，否则禁止改造模板结构；仅允许替换文字内容与少量占位信息
- 单页单主题内容必须使用 `slide_page_1.html`
- 单页出现多个主体且需要突出对比时，必须使用已定义多栏模板（`slide_page_left_right.html` / `slide_page_3_cols.html` / `slide_page_4_cols.html`）
- 结束页直接套用模板，不做内容结构改造
- 单页禁止滚动，内容超限时优先拆页，不通过极端缩小字号硬塞

## 执行模式识别

- Mode A：新建演示文稿（默认）
  - 用户提供文稿或主题，从模板开始完整生成整套页面
- Mode B：增强已有输出
  - 用户指定已有输出目录或已有页面，按现有页面继续补页/改页
  - 修改前先检查是否会造成拥挤或溢出；如会溢出，自动拆分为续页

## 模板注意事项（强检查）

- `slide_main.html` 的 `slides` 数组是播放清单，生成新页面后必须同步更新，且顺序必须与最终演示顺序一致
- 模板使用相对路径加载子页面与图片，生成目录内必须保证 `main.html`、各页 HTML、图片资源处于正确相对位置
- `slide_title.html` 含不规范占位结构（重复 logo 与多处孤立换行标签），生成时应只替换内容，不要扩大改动范围
- `slide_section_title.html` 注释与实际背景文件存在不一致，以实际 CSS 引用为准
- 模板默认含保密与版权文案，交付外部版本前应按用户要求确认是否保留或替换

## 执行流程

1. 模式识别与模板校验
   - 先识别当前任务属于 Mode A（新建）还是 Mode B（增强）
   - 检查 `oracle_slide_template` 目录与必要文件是否齐全
   - 缺失任一关键模板时，直接返回：`找不到 oracle template，请手工拷贝到工作空间。`

2. 读取与规划
   - 读取用户文稿文件
   - 先产出页面规划：总页数、每页用途、每页模板类型
   - 规划必须可映射到现有模板类型

3. 创建输出目录
   - 在 `oracle_slide_template` 下创建新目录，命名建议：`<主题>-<YYYYMMDD-HHMMSS>`
   - 所有生成文件与中间产物都放在该新目录

4. 逐页生成
   - 先按“页面目标”选模板，再写内容，避免先写后套版。
   - 先统计“单主题页 / 多主体对比页 / 展览页”数量，再映射模板，确保满足模板复用率与卡片页次数约束。
   - 推荐结构（可按内容增减与重排，不是固定顺序）：
     - 标题页（`slide_title.html`）
     - 议程页（`slide_agenda.html`）
    - 关键要素页（优先使用 `slide_page_1.html`；仅在展览场景下可使用 1 次 `slide_page_cards.html`）
     - 章节标题页（`slide_section_title.html`）
    - 内容页（单主题用 `slide_page_1.html`；多主体对比用 `slide_page_left_right.html` / `slide_page_3_cols.html` / `slide_page_4_cols.html`；框架分析用 `slide_page_swot.html`）
     - 结束页（`slide_end.html`）
   - 内容页写作要求：
     - 信息要完整、具体、可落地；用户原文过短时可适度补全，但不得偏离主题。
     - 优先“结论先行 + 要点展开”，避免空泛口号与冗长段落。
     - 必要时可调用搜索补充事实、术语解释或行业背景。
   - 单页内容密度上限（硬约束）：
     - 标题页：1 个主标题 + 1 个副标题（可选）
     - 普通内容页：1 个标题 + 4-6 条一级要点，或 1 个标题 + 2 段正文。正文内容要具体、可落地，不能太短，至少要占满页面75%。
     - 单行 4 列卡片：最多 4 卡；两行 3 列卡片：最多 6 卡
     - SWOT：每象限 2-4 条要点
     - 时间线：建议 4-6 个节点
     - 超出上限时必须拆成下一页，不允许通过缩小到不可读字号来压缩
  - 内容模板选型策略（强约束，必须执行）：
    - `slide_page_1.html`：单页单主题正文，默认优先。尽量使用模版中样式来显示内容。
    - `slide_page_left_right.html`：同页 2 主体对比时强制使用。
    - `slide_page_3_cols.html`：同页 3 主体对比时强制使用。
    - `slide_page_4_cols.html`：同页 4 主体对比时强制使用。
    - `slide_page_swot.html`：仅用于 SWOT（2x2）分析。
    - 禁止把多主体对比内容放入 `slide_page_1.html`。
    - 禁止为追求样式变化而新建或重写布局结构。
    - 仅当以上模板都不适配且用户明确要求时，才允许新增布局。
     - 保持阅读顺序清晰、留白充分、层级明确，避免元素拥挤或重叠。
     - 如果需要创建图表，可以使用chart.js图表。
     - 如果内容中有计算机代码，建议使用代码块格式，并使用等宽字体（如Courier New）。代码如果太长，不建议完整显示，可提取关键部分。
   - 视觉与素材约束：
     - 模板背景图必须保留，不得替换。
     - 若引用图片，优先复用模板目录现有文件名与路径策略，避免相对路径失效。
     - 生成完成后，将用到的图片资源复制到输出目录。
   - 页面命名必须按顺序编号（例如 `01_title.html`、`02_agenda.html`、`03_content.html`）。

5. 组装主页面
   - 基于 `slide_main.html` 组装全部页面，保证顺序正确
   - 必须更新 `slides` 数组为实际生成文件列表，禁止保留模板默认示例清单
   - 输出可直接打开的主页面（如 `main.html`）

6. 交付与预览
   - 明确告知输出目录与主页面路径
   - 调用浏览器，打开主页面进行浏览器预览

7. 质量验收清单（交付前必做）
   - 页面可读性：无文字溢出、无滚动条、无重叠遮挡
   - 结构约束：分栏布局有可见分界线；卡片布局有圆角与阴影
  - 模板合规性：模板复用率 ≥ 90%，卡片页使用次数 ≤ 1，且仅用于展览页
  - 选型合规性：单主题页必须为 `slide_page_1.html`，多主体对比页必须使用多栏模板
   - 风格一致性：标题层级、字号梯度、留白节奏保持一致
   - 路径正确性：所有子页和资源路径有效，无 404 / 空白页
   - 播放正确性：`slide_main.html` 的 `slides` 顺序与实际页面一致

## 安全与幂等要求

- 严禁修改模板源文件（`oracle_slide_template` 根目录下模板文件只读使用），每次生成必须读取最新版本的html template文件，用于生成。
- 每次生成必须创建新时间戳目录，避免覆盖历史成果
- 若发现同名输出目录已存在，自动追加后缀避免冲突
- 缺少输入文稿或模板不完整时，停止生成并返回明确缺失项
- 最终交付前必须检查主页面能逐页打开全部子页面，且无 404/空白页

## 输出要求

- 必须输出：
  - 页面规划表（页码、页面类型、页面目标）
  - 生成文件清单
  - 主页面路径
- 失败时必须输出：
  - 失败阶段
  - 缺失文件或错误原因
  - 可执行的修复建议
