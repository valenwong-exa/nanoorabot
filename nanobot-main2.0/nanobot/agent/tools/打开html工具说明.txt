打开html工具说明

1. 文件位置
- 工具代码：nanobot\agent\tools\open_html.py
- 说明文件：nanobot\agent\tools\打开html工具说明.txt

2. 工具用途
- 新增内置工具 `open_html`，专门用于打开本地 HTML 文件或 URL。
- 优先使用 Python 自带的 `webbrowser` 模块。
- 不再依赖 `cmd`、`powershell`、`start` 之类的命令去打开浏览器。
- 这样在 Windows 上更稳，也顺手兼容 Linux 桌面环境。

3. 支持的输入
- `http://...` 或 `https://...` 的网页地址。
- 本地文件绝对路径。
- 相对路径。相对路径会按当前 workspace 解析。
- `file://...` 形式的本地文件 URI。

4. 实现方式
- 入口类为 `OpenHtmlTool`。
- 工具名为 `open_html`。
- 本地路径先做路径解析和权限校验，再转换成标准 `file:///...` URI。
- 最终统一调用 `webbrowser.open(...)` 打开系统默认浏览器。
- Linux 下如果没有桌面会话环境（`DISPLAY` 和 `WAYLAND_DISPLAY` 都为空），工具会直接返回错误提示，避免假成功。

5. 加载方法
- 主 agent 加载入口：`nanobot\agent\loop.py`
- 子 agent 加载入口：`nanobot\agent\subagent.py`
- 已在这两个入口注册 `OpenHtmlTool`，程序启动后会自动加载，无需额外配置。

6. 调用示例
- 打开本地 HTML：
  `open_html(target="dba1/chartjs_demo.html")`
- 打开绝对路径：
  `open_html(target="E:\\nanobot-main\\dba1\\chartjs_demo.html")`
- 打开 URL：
  `open_html(target="http://127.0.0.1:8000/index.html")`
- 打开 file URI：
  `open_html(target="file:///E:/nanobot-main/dba1/chartjs_demo.html")`

7. 设计目的
- 以后 AI 生成 HTML 后，优先调用 `open_html` 进行预览。
- 避免继续尝试 `cmd` / `powershell` 打开浏览器而导致 Windows 下报错。
