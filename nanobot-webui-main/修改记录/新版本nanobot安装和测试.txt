建议方式

- 用 单独目录 + 单独虚拟环境 安装 post3 CLI
- 不要复用当前 nanobot-webui-main\.venv
- 不要在当前 nanobot-webui-main 目录里执行 pip install
推荐目录

- 源码目录： E:\nanobot-main\nanobot-015post3
- 新虚拟环境： E:\nanobot-main\nanobot-015post3\.venv-post3
PowerShell 命令

- 先进入 post3 目录
```
cd E:\nanobot-main\nanobot-015post3
```
- 创建独立虚拟环境
```
py -3.12 -m venv .venv-post3
```
- 激活虚拟环境
```
.\.venv-post3\Scripts\Activate.ps1
```
- 升级基础安装工具
```
python -m pip install --upgrade pip setuptools wheel
```
- 安装 post3 CLI
- 推荐先用普通安装，尽量少影响源码状态
```
pip install .
```
- 如果你后面准备边改边测，也可以改用开发模式安装
```
pip install -e .
```
安装后先验证

- 看版本
```
nanobot --version
```
- 看帮助
```
nanobot --help
```
- 也可以直接用模块方式验证
```
python -m nanobot --help
```
建议再做一个最小运行

- 先建一个独立配置目录
```
mkdir E:\nanobot-main\post3-test
```
- 初始化 post3 专用配置
- 这里我建议先不要直接写到你现有的默认配置位置
```
nanobot onboard -c E:\nanobot-main\post3-test\config.json -w 
E:\nanobot-main\workspace-post3-test
```
然后验证 CLI 是否可用
